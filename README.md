# Lollipop

Lollipop is a futuristic, video-first creator media platform foundation.

## Current foundation

- Next.js web workspace
- Cinematic responsive landing experience
- Video-first discovery surface with synthetic demo media placeholders
- Backend architecture and moderation lifecycle documentation
- Security/privacy-by-design direction

## Planned domains

Identity, creator verification, media processing, moderation, subscriptions, purchases, messaging, payouts, reporting and audit.

> Development repositories must contain only synthetic/demo media references. Production intimate media and identity documents must not be committed to source control.
